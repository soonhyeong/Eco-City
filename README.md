# 에코시티 구조대 · Eco-City

![에코시티 구조대 로고](Assets/EcoCity/Art/Logo/EcoCityLogo.png)

어린이가 물건의 재질과 상태를 살피고, 필요한 처리를 한 뒤 분리배출하는 **3D 환경교육 게임**입니다. 공원·바닷가·시장을 탐색하며 쓰레기를 치우고 에코시티를 되살립니다.

성결대학교 2026 Sungkyul Creative Challenge(SCC) · **겜성충만**

## 게임 소개

플레이어는 쓰레기를 하나씩 주워 상태를 확인합니다. 깨끗한 물건은 알맞은 통에 바로 넣고, 내용물이나 부착물이 있는 물건은 **비우기 → 떼어내기 → 씻기** 중 필요한 과정을 거칩니다.

잘못 배출해도 물건과 처리 상태가 유지됩니다. 도우미의 설명을 읽고 다시 시도할 수 있으며, 올바르게 배출할수록 지역의 분위기가 밝아지고 꽃과 자연이 되살아나도록 구성했습니다.

## 주요 기능

- **3개 지역·12개 연습품**: 기본 분류에서 오염 상태와 부착물 판단으로 학습 조건을 늘립니다.
- **캐릭터 선택과 3인칭 탐색**: 두 캐릭터, 근접 상호작용, 이동 애니메이션을 제공합니다.
- **행동 안내와 도우미**: 그림·표식·처리 방향 안내와 상황별 피드백으로 다음 행동을 돕습니다.
- **지도와 지역별 별**: 지역 해제·완료·현재 위치를 확인하고 최대 9개의 별에 도전합니다.
- **수집과 보상**: 올바르게 배출한 품목을 스티커 도감에 모으고 고깔모자·왕관을 얻습니다.
- **3종 미니게임**: 「번개 분리수거!」, 「먼저 뭐 할까?」, 「맞아요 틀려요!」와 종류별 최고 기록을 제공합니다.
- **환경 회복 연출**: 하늘·꽃·환경음의 변화와 지역·전체 완료 연출을 구성했습니다.
- **저장과 설정**: 진행·부분 처리 저장, 음악·효과음 음량, 감도, 큰 글자, 화면 효과·가벼운 화면 설정을 지원합니다.

| 지역 | 학습 내용 | 품목 수 |
| --- | --- | --- |
| 새싹 공원 | 깨끗한 종이·병·캔 등 기본 분류 | 5개 |
| 반짝 바닷가 | 내용물·오염·부속품에 따른 처리 | 4개 |
| 알록달록 시장 | 라벨·테이프 등 분리 판단 | 3개 |

본편 점수는 정답 배출당 20점, 단계 완료당 30점, 오답 배출 시도당 -2점이며 최저 0점입니다. 현재 12개 품목을 오답 없이 완료하면 **330점**입니다. 지역 별과 미니게임 별은 별도의 기준을 사용합니다.

## 조작

| 입력 | 행동 |
| --- | --- |
| WASD / 방향키 | 이동 |
| 마우스 | 시점 입력·화면 선택 |
| E | 집기·처리·배출·도우미·놀이 부스 상호작용 |
| Esc | 메뉴 / 돌아가기 |
| H | 도움말·행동 안내 |
| 숫자 키 / 마우스 | 미니게임 응답 |

게임패드 입력 대응 코드도 포함되어 있습니다. 기기별 조작과 전체 화면 흐름은 추가 확인이 필요합니다. 음성 안내는 현재 비활성화되어 있습니다.

## 개발 환경

- Unity **6000.2.12f1**
- Built-in Render Pipeline
- Input System, uGUI, TextMeshPro
- Git LFS: 모델·텍스처·음원·폰트 등 바이너리 에셋 관리

## 프로젝트 열기

Git LFS가 설치된 환경에서 프로젝트를 내려받습니다.

```bash
git lfs install
git clone https://github.com/soonhyeong/Eco-City.git
cd Eco-City
git lfs pull
```

Unity Hub에서 `Assets`, `Packages`, `ProjectSettings`가 있는 폴더를 추가하고 Unity 6000.2.12f1로 엽니다. 최초 패키지 복원·임포트·컴파일이 끝날 때까지 기다립니다.

| 씬 | 경로 |
| --- | --- |
| 타이틀 | `Assets/Scenes/EcoCityTitle.unity` |
| 캐릭터 선택 | `Assets/Scenes/EcoCityCharacter.unity` |
| 최신 게임 | `Assets/1. Scene/EcoCitySubmission.unity` |
| 보존 알파 | `Assets/EcoCity/Generated/Submission/Alpha/EcoCityAlpha.unity` |
| 보존 프로토타입 | `Assets/EcoCity/Generated/Submission/Prototype/EcoCityPrototype.unity` |

목표 진행은 **타이틀 → 새 게임·캐릭터 선택 또는 이어하기 → 지역 지도 → 3개 지역 → 결과**입니다. 아래 씬 연결 제약을 먼저 확인하세요. 여러 버전의 게임 씬을 Additive로 동시에 실행하지 않습니다.

## 현재 상태와 알려진 제한

현재 저장소는 Unity 편집용 프로젝트이며 독립 실행 파일의 배포 검증을 완료한 상태는 아닙니다.

- 시작 씬 목록에 최신 게임만 등록되어 있어 타이틀·캐릭터 선택 씬 연결 정리가 필요합니다.
- 기존 6개 품목 저장과 현재 12개 품목 구성 사이의 진행 이전이 필요합니다. 이전 저장의 완전한 호환을 보장하지 않습니다.
- 타이틀의 이어하기 표시에는 저장 내용 유효성과 백업 전용 저장 처리를 보완해야 합니다.
- 실제 플레이·어린이 사용자 테스트·성능·교육 효과는 별도로 검증해야 합니다.

## 학습 규칙의 범위

품목 정답과 준비 절차는 **게임의 가상 연습 규칙**입니다. 실제 배출은 물품 표시와 거주 지역의 안내를 확인해야 합니다. 모든 복합 재질이 일반 쓰레기이거나 세척만으로 모든 오염품이 재활용되는 것은 아닙니다. 깨끗함·오염도는 게임 지표이며 실제 환경 통계가 아닙니다.

## 프로젝트 구조

```text
Assets/EcoCity/
├─ Core/                  판정·미션·점수·진행 데이터
├─ Runtime/               플레이어·상호작용·화면·환경 표현
├─ Editor/                씬 구성·검증 도구
└─ Generated/Submission/  단계별 보존 씬·데이터·재질·음원
Assets/1. Scene/          Eco-City 최종 게임 씬
Assets/Scenes/            타이틀·캐릭터 선택 씬
Packages/                 패키지 의존성과 잠금 파일
ProjectSettings/          Unity 프로젝트 설정
Validation/               외부 검증 도구
```

`Assets`의 `.meta`, `Packages/manifest.json`, `Packages/packages-lock.json`, `ProjectSettings`를 함께 유지하세요. 캐시와 로컬 작업 파일의 제외 기준은 [.gitignore](.gitignore)에 정의되어 있습니다.

## 단계 구분과 검사

| 구분 | 기준 |
| --- | --- |
| 프로토타입 | 프로토타입 전용 씬·표현·도구 |
| 알파 | 알파 전용 씬·에셋·도구 |
| Eco-City 최종 | 현재 게임·여러 단계가 공유하는 코드와 에셋·프로젝트 설정 |

단계 이름은 파일의 사용 범위를 뜻합니다. 이름에 Prototype·Alpha가 있더라도 최종 게임에서 사용하는 공통 코드는 Eco-City 최종에 포함합니다. 이전 단계 문서와 별도 Submission 안내 문서는 정리했으며, 현재 게임 소개는 이 README를 기준으로 확인하세요.

순수 핵심 로직 검사는 .NET 10 SDK에서 실행할 수 있습니다.

```bash
dotnet run --project Validation/CoreChecks.csproj
```

정적 에셋·경로 감사는 PowerShell에서 실행합니다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File Validation/AuditProject.ps1
```

Unity 통합·씬 검사는 편집 내용을 저장하고 검증용 복사 프로젝트에서 수행하세요. 자동 검사와 실제 Play·화면·음향 확인은 구분합니다.

## 출처와 이용 범위

외부 캐릭터·도시·소품·애니메이션은 각 원저작자의 이용 조건을 따릅니다. 한글 글꼴의 OFL과 출처 파일은 `Assets/EcoCity/Fonts`에, 음원 제작 정보는 `Assets/EcoCity/Generated/Submission/KidWorld/Sound/SOURCE.md`에 보존되어 있습니다. 프로젝트 공유·재배포 시 사용하는 에셋별 원본 라이선스를 확인하세요.
